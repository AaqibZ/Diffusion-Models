# Interaction-Oriented Results

This directory contains the statistical results associated with the
Reviewer uncertainty analysis for the stochastic interaction-oriented
diffusion models.

## Experiment

The analysis considers:

- 8 stochastic interaction-oriented diffusion models
- 3 temporal network datasets: CollegeMsg, Email-Eu-Core, and Bitcoin-OTC
- Seed-set sizes: 8, 12, 16, and 20
- Monte Carlo simulations
- 95% confidence intervals

## Result Files

The result files report final activation statistics for each
dataset-model-seed-size combination.

Reported statistics include:

- Mean final activation
- Standard deviation (SD)
- Standard error of the mean (SEM)
- 95% confidence interval (CI)

The corresponding plots visualize the mean activation and uncertainty
associated with the stochastic interaction-oriented models.
