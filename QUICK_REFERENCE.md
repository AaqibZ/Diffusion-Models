## Method 2: Local Web Server 🖥️

### Python (One Command)
```bash
python -m http.server 8000
# Open: http://localhost:8000/diffusion_recommender_web.html
```

### Node.js
```bash
npx http-server -p 8000
```

### VS Code
```
1. Install "Live Server" extension
2. Right-click HTML file
3. "Open with Live Server"
```

## Method 3: Deploy Online (Free!) 🌍

### GitHub Pages (Most Popular)
```bash
1. Create GitHub repo
2. Upload HTML (rename to index.html)
3. Settings → Pages → Enable
4. Share URL: https://username.github.io/repo/
```

### Netlify (Fastest)
```
1. Go to netlify.com
2. Drag & drop HTML file
3. Get instant URL
4. Done in 30 seconds!
```

### Vercel
```bash
vercel --prod
# Instant deployment!
```
